# Prisma Studiereis Stockholm 2026

Interactieve one-page infographic van het persoonlijk ontwikkelverslag van Roy Verberne (BS De Groenling, Stichting Prisma) over de Erasmus+-studiereis naar Stockholm, 18–21 november 2026.

- `index.html`: de pagina (tabbladen Overzicht, Doel 1, Doel 2, Bijvangst, Quick wins, Prisma-gevoel)
- `img/`: foto's en logo
- `verslag/`: het volledige verslag als PDF ("Download verslag")

Statische site, geen build nodig. Gehost op Vercel.
